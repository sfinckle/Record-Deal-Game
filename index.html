The clients

Instructor notes

Setup

  1. Put this one file anywhere students can open it in a browser: your course site or LMS, GitHub Pages, Netlify, or a shared drive. No account or server is needed.
  2. Open the class dashboard on your computer and project or share the five-letter class code.
  3. Pair teams of 2–4, one device per team. One team starts a game (entering the class code) and reads its four-letter game code to the other team.
  4. Run all pairs with the same client first (Hollis is a good warm-up), then switch sides and clients.
  5. If a campus network blocks direct connections, use one-screen mode: teams pass a laptop between turns.

Rules of play

  • 480 Collective makes the opening offer. The teams then alternate offers, and each offer can include a short note.
  • Either side can accept the other side’s offer on its turn, or walk away at any time.
  • After the artist team’s sixth offer, the label’s response is final: the artist must accept or walk.
  • Each team sees only its own value meter and walk-away point. Briefs are confidential — no showing screens.

Debrief

  • Open the class dashboard and compare deals for the same client. Why did outcomes differ so much?
  • Which terms were cheap for the label to give but valuable to the artist? Did teams find those trades?
  • Did anyone bluff about a competing offer? How did the label team decide whether to believe it?
  • Find a deal where the artist is unrecouped in the “expected” case while the label is profitable. Walk the class through why.
  • Did any pair fail to close even though a deal was possible? What got in the way?

Scoring

Each team’s score is the share of the available surplus it captured: how far above its own walk-away point the final deal landed, compared with the best deal the other side would have signed. Walking away scores 0. The numbers are illustrative, based on a simplified model of royalties, recoupment, 360 income and catalog value across flop, expected and breakout outcomes.
